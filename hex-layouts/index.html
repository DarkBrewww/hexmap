Method and metric definitions

Generation

Based on McNeill & Hale (2017), Generating Tile Maps (authors' demo).

  1. Perturb centroids with Noise, run 30 position updates, and interpolate using Transform.
  2. Transform and smooth the containing boundary, then fit a hex grid with one cell per mainland district.
  3. Assign districts to cells using the Hungarian algorithm to minimize squared distance. Ranking weights apply afterward, not during assignment.

Fixed NYU grid

Keep the 436 NYU cells at the exact positions, orientation, size, and spacing used by the morph viewer, including the small drawing gaps. Reuse the generated mode's centroid transformation, then reassign all 436 districts with the Hungarian algorithm. No state or inset restrictions are imposed on assignments. Smooth, Shift, and hex orientation are locked; only Noise and Transform vary.

The original NYU assignment is a reference, not a generated candidate. Save candidates to collect layouts across modes and batches. The main Export JSON button exports all or selected layouts from the current batch, in current rank order. Export saved group exports only the saved layouts, sorted by the current ranking weights.

Metrics

  • Distance: Mean transformed-centroid-to-cell distance, divided by the original grid reference step. It excludes movement caused by Transform. The original NYU reference uses untransformed geographic centers, so its Distance and Score are not strictly like-for-like with transformed candidates.
  • Adjacency: Mean fraction of each district's original neighbors that are no longer adjacent.
  • Orientation: Mean direction error to original neighbors, in radians (0–π).
  • Roughness: Ideal occupied-grid perimeter divided by the equal-area circle's perimeter, minus 1. Drawing gaps are ignored for topology and roughness. This metric is constant in fixed-NYU mode.
  • Original movement: Mean distance from original geographic centroids to assigned cell centers, divided by the same reference step in both modes.

Data and validity

436 districts: 433 mainland, 1 Alaska, and 2 Hawaii. Census geometry uses the Albers USA projection. Generated-grid mode places Alaska and Hawaii near their projected insets and does not use NYU cell positions. Fixed-NYU mode imports the original cell positions and permits reassignment across all cells. All metrics include all districts.

A valid layout assigns every district once to a unique, finite cell on a common hex grid with no overlapping interiors. This does not guarantee preserved adjacency, connectivity, or absence of holes. Self-intersecting containing boundaries are rejected.

Search and reproducibility

Every combination of the entered values is tested, up to 512 per batch—not every possible layout. Duplicate layouts remain listed under their respective parameters. Grid fitting stops after 50 iterations; failure does not prove that no solution exists.

Random seed: 42. The same Noise value shares a sample across other parameters; different Noise values use different deterministic samples. Hex size depends on the transformed boundary and grid fitting. Boundary sampling and inset placement are adaptations, so results can differ from the authors' demo.

State colors

Each state has one consistent, formula-generated color across all views; these colors are not NYU's palette or thematic values. Fifty-one muted hues are not reliably distinguishable by eye. Highlight state keeps one state's districts colored and outlines them while dimming the rest.
