Neighbour-shear test

Generated by experiments/fixed-grid-overlap/shear_test.py from pair-level overlap measured by pair_overlap.cjs on the same 126 candidates as report.html. Linear morph only.

Hypothesis

Direction error goes with overlap, but crossing paths do not explain it (path_crossings.html). Proposed instead: two map neighbours share a border; if their relative position rotates in the layout, the shared border slides, and part-way through the morph one district pushes into the other. If so, overlap should come mostly from map-neighbour pairs, and inside a layout the pairs that slide more should overlap more, with size and approach held fixed.

Measuring overlap per pair

pair_overlap.cjs reads each district's Linear outline from the morph page (the same vertex arrays the page interpolates), fills every outline on a 1,200-pixel-wide grid at 51 moments, and adds up the pixels each pair shares. Check against the page's own Linear overlap at the same moments, over 8058 frames: mean absolute difference 0.16 points, largest 0.51 points; peak difference 0.12 to 0.21 points (ours slightly higher).

Limits

  • Linear morph only: the Forsch hybrid's outlines are computed inside the page and are not exposed, so its overlap was not split by pair.
  • Sliding and approach use centres; the shared border itself is not traced.
  • Pair overlap counts a pixel under three or more districts once, against the first district drawn there.
  • Same candidates as report.html: one generator on one fixed grid.
