# Evidence for the Oct 30 meeting, and the layout evaluation

Each script reads files in this folder or the repository root and prints the numbers used in the meeting notes. The `_output.txt` files are those prints, from running the scripts on Oct 29, so the numbers can be shown without running anything. Scripts need only Python 3 (standard library) or Node.js.

| File | Run | Backs these claims |
|---|---|---|
| `layout_scores.py` | `python layout_scores.py` | Pairs kept, hex pairs, states split and state borders kept for NYU and all six layouts in `friday_layouts.json`; 318 of 1,136 district neighbour pairs cross a state line |
| `county_stats.py` | `python county_stats.py` | The district vs. county table: units, neighbour pairs, share across state lines, units per state, neighbours per unit, and how far a one-tile-per-unit map moves tiles away from land area |
| `hungarian_timing.cjs` | `node hungarian_timing.cjs` | How long the assignment step in `hex-layouts/engine.js` takes for 436 and for 3,142 units |
| `evaluate_layouts.py` | `python evidence/evaluate_layouts.py > evidence/evaluate_layouts_output.txt` | Every grid-map quality facet for NYU and the six layouts: location, adjacency kept and added, direction, Deform-k and OrthoOrder-k (k = 5, 15, 50, 100, all), roughness, footprint shape, state structure, plus the morph scores. Writes `layout_metrics.csv`, `layout_metrics_per_region.csv`, `layout_metrics_summary.md` (definitions, Pareto set, checks) and `layout_scorecard.svg`. Standard library only; first rechecks the numbers in `layout_scores_output.txt` |
| `morph_scores.cjs` | `npm install`, then `node evidence/morph_scores.cjs` | Overlap, self-crossings and area change for every layout and both methods, read from `index.html` in headless Chromium (the page's own 101 frames, as in its CSV download). Writes `morph_scores.csv`, which `evaluate_layouts.py` reads |
| `friday_layouts.json` | import in `index.html` | Our two Meulemans layouts plus four made with `hex-layouts/` at the settings in their IDs (noise n, transform t, smooth s, shift), picked as the two per mode that kept the most neighbour pairs |
| `meulemans_touching.json` | import in `index.html` | Our two layouts drawn with touching hexes, the way generated layouts from `hex-layouts/` are drawn (`node ownlayout/export_layouts.cjs evidence/meulemans_touching.json --radius-ratio=1`) |
| `build_county_regions.py` | `python evidence/build_county_regions.py > evidence/build_county_regions_output.txt` | Writes `data/county_regions.json`: the 3,142 counties in the same schema and screen coordinates as `hex-layouts/data.json` (regions with centre, neighbours, rings and path; mainland, Alaska and Hawaii groups), so `evaluate_layouts.py --regions` and `engine.generate()` take it as they take the districts. Its counts match `county_stats_output.txt` (8,781 pairs, 1,222 across state lines). The mainland group fills the district file's mainland outline, because the 1:10m county outline folds when the generator resamples it to 512 points; `--own-outline` uses the counties' own. Standard library only |
| `county_smoke_test.cjs` | `node evidence/county_smoke_test.cjs > evidence/county_smoke_test_output.txt` | Paul's generator at its default settings on the 3,108 mainland counties (33 s on this run), written to `data/county_mainland_smoke_layout.json`. Mainland only: the generator's inset step places one or two regions per inset, and counties have 29 in Alaska and 5 in Hawaii |
| `county_smoke/` | `python evidence/evaluate_layouts.py evidence/data/county_mainland_smoke_layout.json --regions evidence/data/county_regions.json --group mainland --morph "" --out evidence/county_smoke > evidence/county_smoke/evaluate_layouts_output.txt` | The evaluation of that layout, to show the script runs on counties (14 s). Pass `--out` for county runs; the default writes over the district results in this folder. Location and Deform are in hex steps of each layout's own grid, and county hexes are much smaller (step 8.59 screen units here, against 19.88 to 24.94 for the district layouts), so compare those two between districts and counties only after converting units |
| `county_generated_layout.cjs` | `node evidence/county_generated_layout.cjs > evidence/county_generated_layout_output.txt` | Paul's generator on the full county map at its defaults (the call `hex-layouts/inset-tests.cjs --county` makes), written to `data/county_generated_default.json`: Alaska at scale 0.484 in 2 pieces, Hawaii at 0.823 in 4, 7 tile components |
| `../ownlayout/prep_county_wkt.py`, `../ownlayout/tsv_to_layout.py`, `../ownlayout/runs_county/` | `python3 ownlayout/prep_county_wkt.py ownlayout/input/us_counties_states.wkt`, then `python3 ownlayout/prep_noparts.py ownlayout/input/us_counties_states.wkt ownlayout/input/us_counties_noparts.wkt`; after `ownlayout/build.sh`, `python3 ownlayout/sweep.py ownlayout/input/us_counties_states.wkt ownlayout/runs_county/states 3600 "5 5 0 1"` and the same with `us_counties_noparts.wkt` into `runs_county/noparts` with `JAVA_TOOL_OPTIONS=-Xmx6g` set; then `python3 ownlayout/tsv_to_layout.py evidence/data/county_regions.json evidence/data/county_meulemans_layouts.json meulemans-states-p5-d5-s1=ownlayout/runs_county/states/p5_d5_r0_s1.tsv meulemans-nostates-p5-d5-s1=ownlayout/runs_county/noparts/p5_d5_r0_s1.tsv` | The Meulemans pipeline on counties, with and without state walls, at the district layouts' settings (productivity 5, dilation 5, seed 1). The inputs follow `prep_wkt.py`'s rules for districts; 12 island counties move onto their state's main land (listed when the script runs), among them Virginia's Eastern Shore. The state-walls run takes under a minute; the no-walls run took 30 minutes, almost all in the final assignment step, and runs out of memory at Java's default heap. One run each, not a sweep |
| `county_eval/mainland/`, `county_eval/fullmap/` | `python evidence/evaluate_layouts.py evidence/data/county_generated_default.json evidence/data/county_meulemans_layouts.json --regions evidence/data/county_regions.json --morph "" --group mainland --out evidence/county_eval/mainland > evidence/county_eval/mainland/evaluate_layouts_output.txt`, and the same without `--group mainland` into `county_eval/fullmap` | The three county layouts scored on the 3,108 mainland counties and on all 3,142 |
| `data/counties-albers-10m.json` | input | Census 2017 cartographic county boundaries as TopoJSON, from us-atlas 3.0.1 (https://github.com/topojson/us-atlas, ISC licence in `data/us-atlas-LICENSE.txt`) |

Neighbours are units that share a stretch of border, not just a corner, for both districts (`map_neighbors` in `hexmap_data.js`) and counties (a shared TopoJSON arc).

State FIPS codes in `county_stats_output.txt`: 04 Arizona, 32 Nevada, 56 Wyoming, 51 Virginia, 44 Rhode Island, 11 DC.
